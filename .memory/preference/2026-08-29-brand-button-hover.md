# Brand solid button hover uses accent-secondary

Primary solid CTA hover must not stay on `accent-primary/90` — on Runticket (black brand) that stays near-black. Use `hover:bg-accent-secondary` (Runticket → shade-05 mid gray; Velocity → mint-400).
