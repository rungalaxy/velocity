# Runticket brand theme

Multi-brand via `data-brand="runticket"`. Brand color is black (light) / white (dark for contrast). Default typeface is Inter for body, headings, and `font-stack` (`--font-heading` / `--font-stack` → `var(--font-sans)`). Storybook Brand toolbar switches Runcycl (Velocity) ↔ Runticket.
