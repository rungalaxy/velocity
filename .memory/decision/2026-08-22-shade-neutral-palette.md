# Neutral palette is shade-01…10

Core neutrals are only `color.shade.01`–`10` (`#141414` … `#fdfdfd`; darkest ink `#101010` = shade-02). The old `color.gray.*` scale was removed — semantics reference shade directly (`--color-shade-*` / `bg-shade-*`).
